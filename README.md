# DESAFIOS BEECROWD
O beecrowd tem uma lista vasta de exercícios aos quais o usuário pode treinar um pouco a lógica de programação.

## Intuito 1
A minha ideia geral é só me diverti mesmo, gosto de fazer alguns desafios desse site.

## Intuito 2
Fazer o máximo de desafios possível, principalmente aqueles que mal se encontra soluções na internet.

## Ideias
A princípio estou fazendo todos os desafios em Python, mas penso futuramente em refazer essas lições em outras linguagens, como Java, JavaScript, TypeScript ou PHP.
